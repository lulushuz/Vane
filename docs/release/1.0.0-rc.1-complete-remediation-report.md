## Linux compile correction

The earlier cross-platform pass claim was incorrect: Ubuntu first failed to compile because `RuntimeBypassMode` had no string conversion and the Linux owned child required `Box<tokio::process::Child>`. The filter intent now uses `LinuxHostlistMode`, the launcher boxes the owned child, operation IDs use a process-wide sequence, the Linux executable retains its executable bit, and platform-path tests are host-independent.
